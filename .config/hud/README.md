# Desktop maintenance (HUD design system)

Source of truth: `~/.config/hud/tokens.css` (hand-edited: surfaces, edges, glow, radii, type, motion)
+ `~/.config/hud/colors.css` (GENERATED by matugen from `~/.config/matugen/templates/hud-colors.css`; never edit).

Generated by matugen (edit the template in `~/.config/matugen/templates/`, never the output):
`hud/colors.css`, `hypr/hyprland/colors.lua`, `hypr/hyprlock/colors.conf`, `rofi/colors.rasi`,
`kitty/colors-kitty.conf`, `cava/themes/matugen`, `gtk-{3,4}.0/gtk.css`,
`Kvantum/Matugen/Matugen.{kvconfig,svg}` (Qt widgets, restart Qt apps to see changes),
`ghostty/themes/matugen`, `btop/themes/matugen.theme`. Full list: `~/.config/matugen/config.toml`.

Not templated on purpose: terminal CLI tools (lazygit, yazi, fzf, bat…) use the terminal's ANSI
palette, which kitty/ghostty already take from matugen. The original static Kvantum theme is kept
as `MaterialAdw` (switch back in `~/.config/Kvantum/kvantum.kvconfig`).

| Task | Command |
|---|---|
| New wallpaper + regenerate colours | `~/.config/hypr/custom/scripts/set-wallpaper.sh <file>` (or `CTRL+SUPER+T`) |
| Re-apply HUD theme (waybar, swaync, swayosd, dock) | `~/.config/hud/reload.sh` |

| Reload Waybar CSS only | `pkill -SIGUSR2 -x waybar` (also automatic: `reload_style_on_change`) |
| Debug Waybar | `pkill -x waybar; waybar -l debug 2>&1 \| less` (then restart it normally) |
| Toggle dock | `SUPER+SHIFT+D` |
| Battery saver (blur/shadows off, video wallpaper paused, power-saver profile) | `SUPER+ALT+P` (again to restore) |
| Power profile | click the gauge pill in the bar, or `tlpctl get` / `tlpctl set balanced` |
| Failed services | `systemctl --user --failed`, `systemctl --failed` |
| What covers what | `hyprctl layers` |
| Keybind cheatsheet | `SUPER+/` |

## Dock (Quickshell: `~/.config/quickshell/hud-dock/shell.qml`)

- One dock per monitor, bottom centre. Shows when the workspace is empty, otherwise rests on the
  bottom edge to reveal it. Hides for fullscreen windows.
- Left-click: launch / focus (click again to cycle that app's windows) · middle-click: new window
  · right-click: pin/unpin. The grid button opens the vicinae launcher.
- Pins: `~/.config/hud/dock-pins.json` (desktop-file ids, in order).
- Look: HUD panel, icons tinted with the wallpaper accent (`tint` / `hoverTint` at the top of
  shell.qml), segmented running indicators. Colours come live from matugen's colors.json; edits to
  shell.qml hot-reload.
- Blur is requested by the dock itself (ext-background-effect), shaped to the chamfered panel.
- Toggle: `SUPER+SHIFT+D` (`qs ipc -c hud-dock call dock toggle|on|off`). Logs: `qs log -c hud-dock`.
- Disable: remove `qs -n -c hud-dock` in `~/.config/hypr/custom/execs.lua`. The old hypr-dock
  config is still in `~/.config/hypr-dock` if you want it back (`hypr-dock` + its line).

## Sound (EasyEffects 8)

Presets (`~/.local/share/easyeffects/output`): `Speakers`, `EDX Pro` (3.5 mm jack), `Chu II` (USB DSP),
each as `- Music` and `- Movie`. EasyEffects autoloads the device's Music preset when the output or
route changes (`autoload/output/*.json`); the mode switch keeps the device:

| | |
|---|---|
| Control center → SOUND | Music · Movie · Flat (bypass, for A/B) |
| CLI | `~/.config/hud/audio-mode.sh music|movie|toggle|flat` |

- IEM presets = AutoEq correction (Chu II: HypetheSonics GRAS; EDX Pro: mean of RikudouGoku +
  Super Review) with the bass section replaced by a clean boost + 170–180 Hz mud cut. Music keeps full
  dynamics; Movie adds gentle levelling (dialogue up) and crossfeed. Speakers use bass_enhancer
  (psychoacoustic bass), and Movie levels hard for room-filling dialogue.
- Every preset ends in a true-peak limiter at −1 dBFS (measured: 0 samples over, once settled; the
  first ~second after switching can overshoot while plugins re-initialise).
- Measured EQ accuracy vs design: ≤ 0.9 dB (40 Hz–14 kHz). Generator + measurement scripts were
  run from a scratch dir; the presets are plain JSON and can be edited in EasyEffects.
- EQ band types must be `Bell`, `Hi-pass`, `Hi-shelf`, `Lo-shelf`… (`High-shelf` is silently ignored
  by 8.3). Limiter `release` max is 20 ms.
- The DroidCam loopback sink is hidden (`~/.config/wireplumber/wireplumber.conf.d/60-hide-droidcam-loopback-sink.conf`);
  it used to steal the default output whenever the Chu II was unplugged.
- Old output presets: `~/backup/desktop-upgrade-20261022-195115/easyeffects.tar.gz`.

## Predator (nekro-sense)

Everything goes through `~/.config/hud/predator.sh` (run it without arguments for usage). Driver: the
`nekro_sense` module (`/sys/devices/platform/nekro-acer-wmi`); you're in the `nekro-sense` group, so
nothing needs root.

| Where | What |
|---|---|
| Bar pill (fan icon + CPU °C) | click: Nekro Sense GUI · right-click: fan boost · middle-click: 80% charge limit. Turns amber ≥75°, red ≥88°, filled while fans are boosted |
| Control center → PREDATOR | Boost (fans 100%) · 80% (charge limit) · Sync (keyboard RGB follows the wallpaper accent; turning it off restores the previous effect) · Open |
| `SUPER+P`, Predator key | open/focus the GUI |
| Login (`custom/execs.lua`) | `predator.sh login`: keyboard backlight never times out; re-applies Sync |

The power-profile pill (tlp-pd) and nekroctl both set the ACPI platform profile; use the pill for
day-to-day switching.

## Bar layout

Main bar is 48px (pills 36px, `min-height` in `waybar/style.css`). The second bar, `cava-overlay`,
is a 16px click-through band laid over the bottom of the media pill (`margin-top: -23`); if you
change the pill height, adjust that margin too. Cava hides itself after a few seconds of silence.

## Generated-file gotchas

- matugen runs `post_hook`s in no fixed order; anything that must run after *all* templates
  are written needs its own delay.
- Start desktop daemons through Hyprland (`hyprctl dispatch 'hl.dsp.exec_cmd("...")'`), never
  straight from a terminal: kitty puts each window in its own systemd scope, and closing the
  window kills everything started from it (that's what killed the old dock).
- The kde-material-you-colors step prints a D-Bus traceback ("The name is not activatable") because
  KWin isn't running under Hyprland. Harmless, but that string once ended up as
  `gtk-theme-name` in `gtk-{3,4}.0/settings.ini`; if GTK apps look unthemed, check that line
  (should be `adw-gtk3-dark`).
